HookCode 0.6.2

Replies can be formatted now, in the same language a Hook Workspace document uses: colour, highlight, underline, keyboard keys, and callout boxes for notes, tips, warnings and dangers. A reply shrinks back to plain prose when the formatting is stripped, so it still reads correctly when it is pasted somewhere else.

Copy gives you the words, not the formatting. A reply written in Hebrew or Arabic now reads right to left on its own, the way your own messages do, and Copy leaves out the fence that set the direction.

Conversations are named by the agent, so the list reads like what you worked on rather than the first line you typed.

A coding agent can look at a picture: a screenshot it took, an image on disk, or one you attached. A direct coding chat can attach pictures from the composer.

A direct coding chat writes its own checklist, so the plan is there while the run works instead of appearing empty.

If a project folder is already your own clone, the agent uses your own git, with your credential helper and SSH keys, instead of Hook's bundled copy.

Projects can be deleted from the app, and the deletion reaches your other computers. A folder that holds work is never deleted; only the empty clone Hook made.

The folder picker keeps the level you were reading on screen while it reads the next one, with a spinner, and no longer shows stale project rows.

HookCode 0.6.1

Long conversations now stay fast. When a chat grows large, Hook folds the older turns into one summary before the model reads it, so replies keep arriving instead of failing on a full context. The conversation you read is not rewritten. A chat that is still too long for the model is compacted and retried once before it gives up.

Commands arrived with it. With Advanced on, type a slash in the message box to see what is available. /compact summarizes the conversation right away, in an ordinary chat or in a conversation with a coding agent; a coding agent summarizes its own session.

Remote coding chats can start in any folder on that computer, not only in a project. The folder picker walks one level at a time and lists the folders you star first. A remote chat can be deleted from any device now, and its transcript is removed on the computer that owns it.

Streaming from another computer is steadier too: a long reply no longer drops its own connection, the work does not flicker while tools run, and reopening a chat does not leave a finished turn looking busy.

HookCode 0.6.0

Documents in Hook Workspace can be formatted now: colour, highlight, underline, keyboard keys, and callout boxes for notes, tips, warnings and dangers. The formatting is written in the text itself, so it travels with the document to every device, and a document can never contain raw HTML.

Writing a document works like a word processor. The markup stays out of sight, Backspace removes a letter rather than the colour around it, and a callout or a picture is removed as a whole when you delete at its edge.

A document looks the same everywhere. The preview panel beside a chat, HookCode on your phone and the Workspace window share one set of rules, and a document set to read right to left keeps its direction in every view, with its lists, tables and quotes flipping with it.

The assistant can format a document for you, and can set one to read right to left. Ask it to add a warning box or to make a checklist readable and it writes what the editor shows.

Fixed: a reply could disappear and leave only "Stopped" when you attached a picture to a new chat. If a reply is ever cut short now, Hook says what happened instead of showing a bare status line.

HookCode 0.5.1

Advanced mode now belongs to your account, not to one computer: turn it on here and HookCode on your phone shows the same view, and the other way around. It is still off by default.

Your own model endpoint can now reach your other devices. On a paid plan with cloud sync on, Hook saves one encrypted copy of the endpoint, key and model name on your account, so Hook Workspace and HookCode on your phone use the same provider without the key being typed again. Turn cloud sync off and the key stays on the computer that entered it. A key typed under one account is never uploaded to another account that signs in on the same machine.

On the phone, starting a coding agent on a computer is now an Advanced action, like it is on the desktop: with Advanced off, the chat agent gets the work and decides whether a machine is needed.

HookCode 0.5.0

Your other computers are now part of the app. Settings > Your machines lists every computer signed in to your account, with its name, platform, version and online state. Rename a machine, turn remote work on or off, or forget it; every run records the computer it used.

The New chat menu has Coding agent on another machine. Choose a computer and a project, or create a new project there without typing a path. The conversation is created on that computer, next to its folder and engine.

Direct coding chats can now live on another computer. The transcript, folder and engine stay there; this computer keeps an offline cache, and only a small stub is saved to your account. You can open, steer, stop and rename it from any device. Changing the folder or deleting the chat happens on the computer that owns it.

A run on another computer streams the same answer, plan, tool calls and preview as a local run. Close the window and Hook keeps running in the tray, so the run continues; Quit from the tray stops it. Hook Workspace and HookCode on your phone can control runs too.

Remote previews open through a short-lived link, so nothing needs a forwarded port.

Advanced mode shows machines in the agent tree and pane header; a local or remote run looks the same in the conversation.

This release also includes the secure connection, machine list and sync plumbing behind it. Nothing changes for a single-computer setup.
